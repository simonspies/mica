**Mica/TinyML**

- `Common.lean` — Common TinyML vocabulary for variables, primitive operators, and constants.
- `Heap.lean` — Heap operations and basic facts for TinyML runtime locations and value blocks.
- `Language.lean` — Iris language instance for the TinyML runtime IR, via evaluation-context items.
- `OpSem.lean` — Operational semantics for the TinyML runtime IR.
- `RuntimeExpr.lean` — Runtime TinyML IR, values, and substitution machinery.
